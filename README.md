# IdeaTree · 研究灵感时间轴

一个运行在本机的中文研究灵感工作台。横向是日期，纵向是 idea 分支，保留提出、调研、讨论、暂停、中止、完成和重启的过程。

将一个想法从提出、调研、讨论到继续推进、中止或衍生的过程，整理成一张可交互的时间地图。

## 开始使用

### Windows

1. 安装 [Node.js](https://nodejs.org/) 的 LTS 版本，本程序最低要求 Node.js 20。
2. 在 [Releases](https://github.com/Xiao-air/ideatree/releases/latest) 下载 `IdeaTree-1.0.0-windows.zip`，完整解压到你希望长期保存的位置。
3. 双击 **启动IdeaTree.cmd**，浏览器会打开 <http://127.0.0.1:4317>。
4. 可选：双击 **创建桌面快捷方式.cmd**。之后双击桌面 **IdeaTree** 图标即可打开；移动文件夹后重新创建快捷方式。

首次安装 Node.js 后，如启动器仍提示找不到 Node.js，请重新打开文件夹或终端后再试。下载包不附带 Node.js；应用本身没有需要安装的 npm 依赖。

所有图标、字体回退及 D3 / Lucide 资源均可在本机使用。安装好 Node.js 后，日常运行不需要联网。浏览器窗口关闭不会停止本地服务；重复运行启动器会打开已有服务。

### 从源码运行 / macOS / Linux

安装 Node.js 后，在项目目录执行：

```sh
npm start
```

然后打开 <http://127.0.0.1:4317>。使用终端启动时，可按 `Ctrl+C` 停止服务。Windows 快捷方式脚本仅适用于 Windows。

## 功能

- 日期主轴向右延续；idea 可从主轴或父 idea 的事件继续分支。
- 记录文献调研、导师讨论、实验、计算与状态决策，保留发展历史。
- 同一家族保持在主轴同侧，按时间跨度复用空闲行，减少交叉和纵向空白。
- 推进中的 idea 优先显示，已中止的 idea 归入左侧底部“已归档”。
- `Ctrl + 滚轮` 缩放整个页面；`Shift + 滚轮` 只缩放时间轴。
- 数据本地保存，支持 JSON 导入、导出及自动备份。

## 记录方式

- 首次打开的是明确标注的示例空间。点击 **开始我的记录**，确认后建立空白空间。
- **新建 idea**：填写简称、核心问题、首次提出时间与初始状态。
- **记录事件**：记录文献调研、导师讨论、计算或实验及决策。状态变化必须保留原因。
- **衍生 idea**：从当前 idea 或一条具体事件创建子分支。子分支与父分支的状态独立。
- 点击当前状态可以记录新的决定。重启已中止的 idea 时，选择“推进中”；过去的中止记录会保留。
- 左侧可以展开或折叠子分支。拖动画布平移，使用加减按钮缩放；**今天**定位到今天，**适应全部**还原完整范围。
- 右侧详情展示完整事件。图上的标签会在拥挤时省略，完整内容仍可通过点击查看。
- 只记录已发生的事件，日期不能晚于今天。已衍生子分支的来源事件不能单独改变日期或删除。

## 数据和备份

实际记录保存到 **data/ideatree.json**，与浏览器缓存无关。每次保存会先将旧版本写入 **data/backups/**，保留最近 30 个版本。程序只监听本机地址，不会将研究记录上传到云端。

公开仓库和下载包只包含应用与通用示例，不包含作者的个人记录。你的 `data/`、备份、日志和 `.env` 文件已被 Git 忽略。迁移或更新应用前请先导出备份，并保留原来的 `data/` 文件夹；不要把个人导出文件加入仓库。

**导出备份**下载当前空间的 JSON。**导入备份**会先校验内容，再确认替换当前空间。可导入 `data/backups/` 中的历史文件以恢复记录。请定期导出重要记录；自动备份不能代替异地备份。

多个窗口同时编辑时，后保存的旧版本会被拒绝，避免覆盖其他窗口的修改。遇到保存失败，请保持页面打开、导出当前备份，再刷新。数据文件损坏时，服务会停止启动，不会静默重建并覆盖。

## 项目结构

```text
public/            界面、时间轴、共享数据校验
public/assets/     应用图标与 Windows ICO
public/vendor/     本地 D3 7.9.0、Lucide 0.468.0 及许可证
server.mjs         本地 HTTP 服务与 JSON 持久化
start.ps1          Windows 本地启动器
create-shortcut.ps1 根据当前目录创建桌面快捷方式
tests/             数据与保存逻辑测试
data/              首次启动时创建的个人记录（不提交版本管理）
```

执行 `npm test` 运行测试。测试使用独立临时目录，不修改实际记录。

首版面向个人本地使用，不包含云同步、账号、多用户协作或未来计划排期。主时间轴可向未来平移，但实际历史节点只记录到今天。

## 第三方资源

D3 与 Lucide 随项目本地分发，对应许可证保留在 `public/vendor/`。界面使用系统字体，无远程字体请求。
